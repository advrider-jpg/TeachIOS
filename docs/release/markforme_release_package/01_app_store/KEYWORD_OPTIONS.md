# App Store keyword options

Apple indexes the app name and company name already, so do not repeat **MarkForMe** in the keyword field.

## Recommended keyword field

teacher,marking,rubric,feedback,assessment,student,school,classwork,PDF,homework

Bytes: 83

## Alternate for secondary teachers

teacher,marking,rubric,feedback,assessment,student,essay,school,PDF,gradebook

Bytes: 82

## Alternate for primary teachers

teacher,marking,feedback,student,school,rubric,classwork,homework,report,PDF

Bytes: 78

## Words to avoid

Do not use competitor names, school-system names, Apple names, ACARA as a keyword, or names of other apps.
