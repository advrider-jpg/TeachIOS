# Naming note — MarkForMe

## Why MarkForMe works

MarkForMe is short, memorable and plain. It says the job clearly: the app helps mark work for the teacher.

It is stronger than Mark My Work because it does not sound like a student's own assignment app. It is stronger than Marking Mate because the Mark Mate / MarkMate area is crowded.

## Required subtitle

Use **Teacher marking help** as the subtitle. This makes clear that the app is for teachers.

## Main wording risk

The name sounds like delegation. That is useful because it speaks to the pain of marking load. But the copy must make teacher review clear.

Do not say:

- Fully automatic marking.
- AI marks your class.
- Replaces teacher judgement.

Say:

- Mark student work. Check the result.
- Review, edit and approve.
- Teacher judgement stays with the teacher.

## Clearance still needed

Before release, check:

- App Store Connect name availability.
- IP Australia trade marks.
- Common-law use in education software.
- Domain and social handle availability.
- Similar names including Mark For Me, Mark4Me, MarkMe, Mark My Work, Mark My Words, MarkMate and Mark Mate.
