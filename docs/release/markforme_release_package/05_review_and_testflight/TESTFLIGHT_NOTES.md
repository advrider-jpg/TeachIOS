# TestFlight Notes

Please test MarkForMe with fake student work only.

## What testers should test

1. Create a class and assignment.
2. Add or import a roster.
3. Paste student work.
4. Scan paper work on a physical device.
5. Import a PDF or selected photo.
6. Add a rubric, marking guide, criteria, answer key or task instructions.
7. Check the scanned text before marking.
8. Check evidence from the student's work.
9. Mark the work manually.
10. Try draft marking on a supported device.
11. Edit marks and feedback before approval.
12. Approve the final result.
13. Export student feedback.
14. Export a teacher record.
15. Confirm student-facing exports do not show private teacher notes.
16. Confirm teacher-only exports show a warning.
17. Try Airplane Mode and confirm the app does not ask for an account or cloud service.

## Privacy reminder

Student work is not sent to us for marking. Student work stays on your device unless you choose to export or share it. Always follow your school's policy before entering student information into any app.

## Known issues and caveats

- Draft feedback is available only on supported devices and OS versions.
- Xcode archive, TestFlight upload and physical-device smoke tests are still manual release blockers.
- Screenshot templates are not final App Store screenshots.
