## Permission copy

Camera:

MarkForMe uses the camera to scan student work so you can check the text before marking.

Photos:

MarkForMe imports selected images of student work so you can check the text before marking.

Face ID:

MarkForMe uses Face ID to confirm exports that may contain student work.
