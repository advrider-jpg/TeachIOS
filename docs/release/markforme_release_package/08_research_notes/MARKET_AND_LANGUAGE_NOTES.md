# Market and language notes

## Main teacher pain

The strongest message is not novelty. The strongest message is marking load.

Use words teachers already use:

- marking
- student work
- rubric
- marking guide
- success criteria
- criteria
- feedback
- evidence
- teacher judgement
- final result
- student feedback
- teacher record
- class set

## Main trust message

Teachers need to know they stay in control.

Use:

- Check the evidence.
- Review, edit and approve.
- Teacher judgement stays with the teacher.
- Nothing is final until you approve it.

## Main privacy message

Do not say local-only as the lead line.

Say:

- Student work is not sent to us.
- Student work stays on your device unless you export or share it.
- Always follow your school policy.

## Words to avoid

- local-first
- on-device
- OCR validation
- AI grading
- automated assessment engine
- human-in-the-loop
- stakeholder
- workflow
- autonomous marking
- curriculum compliance
- data pipeline
- edtech solution

## First audience

The best first audience is Australian teachers marking text-based student work with a rubric or marking guide.

The strongest initial use cases are English, HASS and other written-response tasks.
