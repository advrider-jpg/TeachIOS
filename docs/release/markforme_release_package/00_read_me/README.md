# MarkForMe release package

This package prepares as much of the release material as possible without running Xcode, creating a signed build, opening App Store Connect or taking real device screenshots.

The work is grounded in the uploaded repo and your feedback:

- The current repo is named **MarkForMe** and describes a teacher-controlled app for marking text-based student work.
- The app supports scan, import, paste and PDF input.
- The app asks the teacher to check scanned text before marking.
- The app works with rubrics, answer keys, exemplars, teacher instructions and mapped Australian Curriculum references.
- The app creates draft marks and feedback where supported.
- The teacher reviews, edits and approves final marks and feedback.
- The app can export student feedback, teacher records, CSV gradebooks, ZIP archives and backups.
- The privacy review says the current release should remain **Data Not Collected** only while there is no developer-accessible data transmission, analytics, crash reporting, ads, accounts, cloud OCR, cloud marking, backend sync, support upload or hosted curriculum download.

## Recommended public name

**MarkForMe**

## Recommended App Store subtitle

**Teacher marking help**

## Main promise

**Mark student work. Check the result.**

## What is included

- App Store metadata and App Review notes.
- Plain-English product copy.
- Screenshot captions and screenshot layout templates.
- Generated logo, wordmark and icon assets.
- A basic support site with privacy, support, FAQ and contact pages.
- A school-facing one-pager.
- Repo patch draft for changing the display name and permission copy.
- Naming and release notes that flag what still needs clearance or real testing.

## Important limits

The screenshot images in this package are templates only. Replace the screen area with real captures from the app before uploading to App Store Connect.

The name **MarkForMe** still needs App Store Connect availability, domain availability and trade mark clearance before launch.

The support and privacy URLs are not configured. Do not submit this package until the release owner supplies working URLs and contact details.

See `05_review_and_testflight/RELEASE_STATUS.md` and `05_review_and_testflight/RELEASE_BLOCKERS.md` for the current blocked release state, required evidence, owners, and exit criteria.

The package does not include a signed archive, Xcode screenshots, App Store Connect data entry, legal advice, trade mark clearance or final privacy-law sign-off.
