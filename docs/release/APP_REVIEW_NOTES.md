# App Review Notes

No account is required. No test credentials are needed.

Use the paste-text/manual review flow on simulator if camera scanning or Apple Intelligence is unavailable. Student-facing export remains blocked until the teacher approves a current final grade. Sensitive teacher-only exports require a warning and local authentication where available.

On eligible devices with Apple Intelligence enabled, local draft feedback can be tested after adding student text and a rubric. If Apple’s on-device language model is unavailable, Mark My Work shows a local-unavailable state and does not use a cloud fallback.

The bundled Australian Curriculum references are local offline reference aids. Mark My Work does not claim ACARA endorsement, certification, compliance, or jurisdiction reporting approval. Teachers explicitly map references before the references enter grading packets. Official catalog entries are read-only in the app.
