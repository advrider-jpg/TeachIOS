# Mark My Work Privacy Policy

Last updated: June 8, 2026

Mark My Work is designed as a local-first teacher grading assistant. The app stores student work, OCR text, rubrics, draft feedback, final reviews, class records, exports, and backups locally on the device unless the teacher chooses to export or share a file through iOS.

## Data collection
Mark My Work does not collect data from the app and transmit it to the developer. The app does not include developer analytics, advertising SDKs, tracking SDKs, account login, cloud sync, cloud OCR, cloud grading, crash-report upload, or a backend service.

## Data stored on device
The app may store the following information locally on the device:

- class, assignment, and student identifiers entered by the teacher;
- scanned images, imported PDFs, pasted student work, and OCR text;
- rubrics, answer keys, exemplars, teacher instructions, and curriculum mappings;
- local draft feedback where supported by the device;
- teacher-edited final reviews, scores, feedback, private teacher notes, and audit history;
- teacher-created exports, archives, and backups.

The app marks its local app-storage directory and sensitive files as excluded from device backup where the platform supports that file setting. Device-level backup, MDM, family-sharing, school-device management, and other operating-system or institution controls remain governed by the teacher’s device, Apple account, institution, and local policy.

## On-device processing
OCR and PDF processing run locally through Apple frameworks. Local AI drafting uses Apple’s on-device language-model capability only when the operating system and device make it available. If the local model is unavailable, Mark My Work does not fall back to a cloud model.

## Teacher-controlled exports
Teachers can export student-facing reports, teacher audit reports, CSV gradebooks, ZIP archives, and backups. Exported files may contain student information. Once a teacher shares, saves, messages, uploads, prints, or otherwise exports a file outside Mark My Work, the destination app, service, device-management system, or recipient controls that copy.

Sensitive teacher-only exports require an in-app warning and local authentication where available. Clipboard export uses an expiring local-only pasteboard item.

## Permissions
Mark My Work requests camera access to scan student work for on-device OCR. It requests photo-library access only to import teacher-selected images of student work. It may request Face ID, Touch ID, or passcode authentication to confirm sensitive export actions.

## Children and students
Mark My Work is a teacher tool. It is not designed for students to create accounts, submit work to the developer, or communicate with the developer. Teachers and schools are responsible for using the app in accordance with their legal, institutional, consent, retention, and student-data-handling obligations.

## Support requests
Do not include student work, student names, grades, private notes, or other personally identifiable student information in support requests. If support requires troubleshooting, describe the problem without sending student records.

## Changes
This policy should be updated before release if the app adds accounts, analytics, crash reporting, cloud sync, hosted curriculum updates, remote AI, support upload, subscriptions, or any developer-accessible data flow.
